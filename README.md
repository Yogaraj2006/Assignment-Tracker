# Assignment Tracker

A simple web app for students to track college assignments and due dates.

## Features
- Add new assignment with subject name
- Set due date for each assignment
- Mark assignment as completed
- View pending and completed assignments
- Simple and easy to use interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Download Assignment-Tracker.zip file
2. Extract the zip file
3. Open index.html in browser
4. Add your assignments and track them
